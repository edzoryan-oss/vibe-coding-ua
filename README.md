# Вайб-кодинг українською

Практична українська база для тих, хто створює сайти, застосунки й автоматизації разом з AI. Тут немає «чарівних промптів»: є шаблони, перевірки та правила, які допомагають отримати робочий результат і не віддати моделі паролі чи API-ключі.

Проєкт доповнює сайт [«Вайб-Кодинг»](https://vibe-coding.com.ua/) і Telegram-спільноту [Вайб-Кодинг](https://t.me/vibecoding_ua).

## Кому це стане в пригоді

- новачкам без досвіду програмування — щоб пройти шлях від ідеї до простого MVP;
- підприємцям і авторам — щоб правильно описати задачу й перевірити результат;
- розробникам — щоб швидше готувати специфікації, прототипи та перевірки;
- командам — щоб узгодити однаковий процес роботи з ChatGPT, Codex, Claude або Gemini.

## Швидкий старт

1. Заповни [короткий опис проєкту](templates/project-brief.md).
2. Передай його AI разом зі [стартовим промптом](prompts/start-project.md).
3. Проси виконувати роботу невеликими етапами та перевіряй кожен результат.
4. Перед публікацією пройди [чекліст запуску](checklists/launch-checklist.md).
5. Якщо проєкт має API-ключі, спочатку прочитай [правила роботи із секретами](security/secrets.md).

## Чотири правила здорового вайб-кодингу

1. **Спочатку результат, потім інструмент.** Опиши, хто користувач і що він має зробити.
2. **Одна перевірювана зміна за раз.** Великі завдання розбивай на короткі етапи.
3. **AI пропонує, людина перевіряє.** Запускай тести, дивись мобільну версію, перевіряй факти й доступи.
4. **Секрети не належать промптам і репозиторіям.** Використовуй змінні середовища та негайно відкликай засвічені ключі.
