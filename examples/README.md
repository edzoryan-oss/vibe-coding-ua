# Реальні українські кейси

У цьому розділі мають з'являтися лише перевірені історії від авторів або команд, які дали згоду на публікацію. Ми не вигадуємо людей, цитати, цифри чи результати.

## Що можна запропонувати

- сайт, застосунок або автоматизацію, створені з допомогою AI;
- розбір помилки й спосіб, який реально її виправив;
- порівняння двох підходів на одному завданні;
- коротку історію від ідеї до запуску з чесними обмеженнями.

## Мінімальна структура кейсу

1. Автор або команда та явна згода на публікацію.
2. Початкова задача й аудиторія.
3. Використані інструменти та причина вибору.
4. Що робила людина, а що — AI.
5. Що спрацювало, що не спрацювало і як це перевірили.
6. Витрати часу й коштів, якщо автор готовий їх назвати.
7. Посилання на результат або відтворюваний приклад.

Не додавай персональні дані клієнтів, приватні репозиторії, ключі, внутрішні документи або скриншоти без дозволу.

Запропонувати кейс можна через GitHub Issue або в [Telegram-чаті «Вайб-Кодинг»](https://t.me/vibecoding_ua).
