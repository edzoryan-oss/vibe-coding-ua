# Як долучитися

Дякуємо за бажання покращити українську базу з вайб-кодингу.

## Перед пропозицією

- перевір, що матеріал дає практичний, відтворюваний результат;
- додай офіційне першоджерело для фактів про сервіс або API;
- перевір код і чітко вкажи середовище, у якому він запускався;
- пиши своїми словами українською, без прихованої реклами й SEO-спаму;
- не додавай приватні дані, секрети або чужі матеріали без ліцензії.

## Для Pull Request

Опиши:

1. яку проблему вирішує зміна;
2. для кого вона корисна;
3. як перевірити результат;
4. які джерела використано;
5. що може бути обмеженням.

Для реального кейсу потрібна згода автора на публікацію. Рекламні та партнерські матеріали не приймаються без окремої прозорої домовленості.
